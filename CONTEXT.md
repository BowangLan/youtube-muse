# YouTube Muse

YouTube Muse organizes music and video discovery into a continuous listening experience across multiple catalogs.

## Language

**Playback Session**:
The continuous listening context that carries the selected track and playback intent as listening moves between sources.
_Avoid_: Player session, playback runtime

**Catalog Search Session**:
The discovery context connecting a query and catalog filters to their results and the playable tracks among them.
_Avoid_: Search transaction, search runtime
